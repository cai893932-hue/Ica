# Ica

Python 算法练习仓库。每天一道 LeetCode，写清难点 / 思路 / 复杂度后提交。

## 关于编号

文件名 `lcN-题名.py` 中的 **N 是 LeetCode 题号**（题目固有编号，不连续）；
commit 里的 `dayN` 是**打卡第几天**（按日期连续 +1）。两套编号独立，不需要相等。
例：`day27: LC145 二叉树的后序遍历` = 第 27 天做了第 145 题。

### 为什么看文件历史会以为题目重复

Git 和 GitHub 网页**默认不追踪文件重命名**：某个文件被改名后，网页上看起来像"那天才首次出现"。
本仓库有 3 次改名，别被误导（真实归属以下表为准）：

- `lc1-two-sum.py` → `lc1-两数之和.py`（day9 改名，题其实是 **day3** 做的）
- `is_palindrome.py` → `lc9-回文数.py`（day9 改名，题其实是 **day2** 做的）
- `lc-19删除链表...py` → `lc19-删除链表...py`（day27 改名，题其实是 **day14** 做的）

想看到完整历史，用 `git log --follow -- 文件名`；判断某题归属哪天，看下面索引表的 day 列。
另外 day9 那天还顺手把 lc20 的注释改精确了（题本身仍是 day5 做的），所以一个 commit 可能碰多个文件，属正常。
