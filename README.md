# Ica

Python 算法练习仓库。每天一道 LeetCode，写清难点 / 思路 / 复杂度后提交。

## 关于编号

文件名 `lcN-题名.py` 中的 **N 是 LeetCode 题号**（题目固有编号，不连续）；
commit 里的 `dayN` 是**打卡第几天**（按日期连续 +1）。两套编号独立，不需要相等。
例：`day27: LC145 二叉树的后序遍历` = 第 27 天做了第 145 题。
